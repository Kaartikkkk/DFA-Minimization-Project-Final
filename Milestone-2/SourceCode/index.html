      How Minimization Works

      A simple 4-step walkthrough

      Phase 1

      Remove Unreachable States

      Starts at the initial state and visits all reachable states. Any state that cannot be reached is discarded.

      Phase 2

      Find Matching States

      Compares state pairs. States that produce identical outcomes on all symbols are marked as equivalent.

      Phase 3

      Merge State Groups

      Combines equivalent states into single composite states, rewiring all transitions cleanly.

      Phase 4

      Verify Equivalence

      Tests strings through both machines to mathematically verify that the minimized DFA accepts the exact same language.

      How It Works

      The 4-step minimization pipeline

      1

      Input & Validation

      The user enters states, alphabet, start state, and accepting states. Any missing transitions automatically connect to a trap/dead state.

      2

      Remove Unreachable States

      Breadth-First Search (BFS) explores all states starting from the initial state. Any state that cannot be reached is removed.

      3

      Find Equivalent States

      The algorithm checks which states behave identically on every input. States that lead to the same outcomes are grouped together.

      4

      Build & Verify Minimized DFA

      Each group of equivalent states is merged into a single state, creating the minimal DFA. The result is verified with string tests.
